# Heart Disease Prediction — Machine Learning Project

An educational binary-classification project using a small, commonly used heart-disease dataset. It demonstrates leakage-aware preprocessing, model comparison, stratified cross-validation, evaluation metrics, and an optional Streamlit demo.

> **Important medical disclaimer:** This project is for learning and demonstration only. It is not a medical device, has not been clinically validated, and must not be used to diagnose, screen, or make treatment decisions for any person. The dataset is small and may not represent current or diverse patient populations.

## Features

- Exploratory data analysis notebook
- Train/test split with stratification
- Preprocessing inside scikit-learn pipelines to reduce leakage
- Comparison of Logistic Regression, K-Nearest Neighbors, RBF SVM, Random Forest, and Gradient Boosting
- Stratified cross-validation on the training set
- Accuracy, precision, recall, F1, ROC-AUC, confusion matrix, and classification report
- Optional Streamlit interface for demonstrating predictions
- Reproducible random seed and saved evaluation artifacts

## Dataset

`data/heart.csv` contains 303 rows and 13 input features plus the binary `target` column. The feature names follow the dataset's original conventions. The target labels should be interpreted only according to the source dataset's definition, not as a real-world diagnosis.

## Setup

Python 3.10 or newer is recommended.

### Windows (PowerShell)

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train.py
```

If PowerShell blocks activation, you can use Command Prompt instead:

```bat
.venv\Scripts\activate.bat
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python train.py
```

## Run the Streamlit demo

First run `python train.py` so that the fitted pipeline is created, then:

```bash
streamlit run app.py
```

The demo is intended to show how a model interface works. Its output is not medical advice.

## Evaluation methodology

1. Reserve a stratified test set before fitting preprocessing or models.
2. Fit scaling/encoding within each model pipeline, so preprocessing is learned only from each training fold.
3. Compare models using stratified cross-validation on the training data.
4. Select the model by mean cross-validated ROC-AUC, then evaluate it once on the held-out test set.
5. Review recall, precision, F1, ROC-AUC, and the confusion matrix rather than relying on accuracy alone.

The selected model can vary by environment and dataset split. Run `python train.py` to generate the actual results in `reports/metrics.json` and `reports/classification_report.txt`. Do not copy performance claims into a resume unless they match your run and you can explain the evaluation.

## Limitations and next steps

- The dataset is small, so metrics have substantial uncertainty.
- This project does not establish clinical validity, fairness, calibration, or external generalization.
- Consider adding calibration analysis, subgroup/error analysis where ethically and statistically appropriate, and external validation before making any real-world claims.
